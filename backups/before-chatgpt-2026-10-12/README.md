# JARVIS local foundation

This is local memory, keyword search and a sales pipeline. It does not yet reason, browse, send email or run a model.

Open PowerShell in this folder and run:

```powershell
.\jarvis.cmd status
.\jarvis.cmd search "client acquisition"
.\jarvis.cmd prospects
```

Use `jarvis.cmd add-prospect --help` to see the required prospect fields. Do not add old leads without current evidence. The launcher uses this computer's bundled Python runtime; another computer would need its path adjusted.

Imported text stays in local storage. Source excerpts and historical AI instructions do not grant action permissions. No background service or automated external actions are configured.
