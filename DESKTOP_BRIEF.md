# Desktop app brief

12 October 2026. Native lightweight Tkinter app in existing JARVIS folder. Scope: typed chat, local conversation history, offline search, local tasks, push-to-talk via installed Windows recognizer, read-aloud, startup at user sign-in, configurable daily briefing (default 08:00 SAST). Retain CLI and account connection.
Acceptance criteria: (1) chat streams without blocking UI and only complete responses enter AI history; (2) context remains optional with preview/approval, historical text is not authorization; (3) startup registration is reversible and opens minimized, single instance enforced; (4) local briefing shows once per SAST day after configured time and catches up after sleep/login; (5) speech inserts recognized text for review, never sends automatically.
Assumptions: Windows session must be signed in; app must be running for briefing. No waking powered-off device. Morning brief uses local tasks/prospect records, not fresh web/email research. Voice depends on installed Windows speech engine/microphone. No always-on microphone or new package/model installs. Website launch checklist not applicable to native desktop app; no website changes.
